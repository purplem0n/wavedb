### Changed

- **Wave Studio:** Schema page uses a compact stats bar, masonry-style table cards (no row-height stretching), and accent **Edit** buttons with icons for table schema changes; sidebar table rows include the same **Edit** control.
- **Wave Studio:** Logs view uses the same compact stats bar and header toolbar layout (kind filter and SQL search beside the title); nav and page title read **Logs**.
- **Wave Studio:** Table browser footer combines row stats, pagination, and engine version on one row; the global shell footer is hidden on table routes to avoid duplicate version text.
